# Grafana — собственная ссылка «Открыть»

Дата: 2026-10-11 (Europe/Belgrade). Итог: PASS.

Пройдены 16 собственных Python-регрессий издателя/конфигурации на Python 3.13.7, Black/Ruff и строгий MyPy изменённого издателя. Ревизия 3 публикует ссылку группы и нативного процесса из прежних PUBLIC_HOST/PORT; адрес внутренней health-пробы не выдаётся браузеру. Остальные части ссылку не наследуют.

Настоящая оболочка приняла публикацию по JWT/mTLS; read-only браузерный тест открыл существующий интерфейс в отдельной вкладке с непустым содержимым, без opener и Referer. Сохранён собственный вход Grafana; анонимный доступ не включался. Тест не создавал фиктивных модулей, identities или Docker-ресурсов. Обновлялся только собственный издатель, нативный процесс и данные сохранены.

Проверки и запуск: test/test_status_publisher.py и README.md владельца; сводная браузерная проверка — [отчёт оболочки](../../../platform-ui/test/open-links-validation-result.md). Локальная PKI и операторский тест не доказывают WAN, внешнюю PKI, резервное восстановление или выполнение административных команд.
