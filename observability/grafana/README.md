# Grafana

Панели, исследование телеметрии и уведомления инфраструктуры.

## Основные возможности

- Панели владельцев и общие источники телеметрии.
- OIDC-вход и разграничение прав.
- Правила и каналы уведомлений.

## Запуск

После подготовки по [руководству](PROVIDER_OPERATIONS.md), из этого каталога:

```sh
docker compose config --quiet
docker compose up -d --no-build --pull never
```

Первоначальная сборка, обновление и восстановление описаны в руководстве. При работе через общую инфраструктурную композицию не запускайте отдельный проект поверх тех же данных.

Для нового локального владельца [local-publisher.py](local-publisher.py) выполняет обычный OIDC-вход оператора и выдаёт отдельный Viewer-токен с Edit только новой папки. Временная identity установки правил выдаётся отдельно и снимается после развёртывания. Параметры и восстановление неизвестного результата — в [руководстве](USER_MANUAL.md#первичная-локальная-выдача-через-oidc).
