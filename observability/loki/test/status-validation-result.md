Модульные тесты: `python3.13 -m pytest -q test/test_status_publisher.py` после установки собственного Poetry-окружения. Браузер: из родительской поставки `python3.13 loki/test/status_publication.py` с обязательными аргументами из [README](../README.md). [Полный отчёт этапов](status-publication-result.md), [снимок](status-publication.png).

Использованы настоящие контейнеры, OIDC, HTTPS API и DOM. Проверка независимости сравнивает исходное и новое время наблюдения других владельцев, а не только зелёный цвет. Подмена системного времени не применяется: серверный TTL истекает в реальном времени, ускоряется только минутный опрос браузера. Никакие тестовые identities, Kafka, контейнеры, сети или тома самим браузерным тестом не создаются. Все stop/start восстановлены в `finally`.

Рабочая строка, машинная identity и журнал созданы отдельным развёртыванием и оставлены для ручной проверки; журнал последовательности не является одноразовым тестовым кэшем. Нативные связи хранения/доставки телеметрии не менялись. Браузерная проверка не подтверждает WAN, продукционную PKI/SVID или восстановление резервной копии.
