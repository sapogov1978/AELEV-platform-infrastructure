# История изменений

- 2026-11-06: локальная библиотека `aelev-observability-tools` обновлена до patch-версии 1.0.1; тестовая PKI теперь содержит SKI/AKI для строгой X.509-проверки, без изменения production PKI и принятого стека.

- 2026-10-23: подготовлены локальная лёгкая живость и исходный `restart=no` для существующего контроллера ADR-0155. Новая проба не опрашивает внешние зависимости, данные/PKI и upstream не меняются. Сборка и рабочая установка различаются в [протоколе](../../test_infrastructure/light-probes-result-20261023.md).

- 2026-10-23: собственный издатель использует SQLite 3.53.4 при прежних Python/ОС/SDK и явную конечную restart-политику. Полный журнал проверяется до замены; UUID, последовательность и прежний бюджет сохраняются. Проверка сборки не подменяет фактическую установку.

- 2026-10-19: подключена автономная read-only проба heartbeat из клиента Platform UI 1.1.1 без импорта издателя и сетевых подключений. Сохранены собственные UUID, журнал, пороги и интервалы; нативный провайдер и его готовность не меняются.

- 2026-10-14: самостоятельная поисковая проекция журналов, TLS, постоянный том, readiness и публикация состояния сверены 16 проверками; продукт отмечен `PRODUCTION_READY`, исходные пакеты остаются в Telemetry Delivery.

- 2026-10-14: эксплуатационное содержание перенесено из README в локальный `USER_MANUAL.md`; краткий README и карта каталога сохранены отдельно. Runtime не изменён.

- 2026-10-11: Добавлены дерево файлов и каталогов, происхождение и подготовка секретов, разграничение локальной и рабочей PKI, права хранения и порядок ротации. Реальные env/удостоверения и рабочие контейнеры не изменяются.

- 2026-10-11: сверена документация самостоятельной поставки; добавлены обслуживание в действующем Compose-проекте, собственная резервная копия/изолированное восстановление, обновление без удаления данных и полная команда UI-теста с условиями безопасности. Нативные версии, права, конфигурация и контейнеры не меняются.

- 2026-10-11: нативный процесс и его операционные файлы включены в собственную каноническую поставку; родитель только оркестрирует. Данные, identities и закреплённые версии сохранены. Добавлены отдельная подготовка, обязательные собственные настройки, конфигурационные регрессии и проверка реального запуска.

- 2026-10-10: верхняя строка собственного состояния переименована в «Хранение и поиск журналов» (`Log storage and search`), ревизия описания 2. Продукты видны внутри прежнего состава; UUID, identity, журнал и последовательность не меняются. Таблица переименований в оболочке не создаётся.

- 2026-10-10: добавлена самостоятельная UI-часть Loki с отдельной строкой, собственными двумя компонентами, image/identity/outbox и Python-проверкой остановки/возврата и независимости других публикаций.
