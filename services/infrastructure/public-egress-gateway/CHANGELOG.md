# Changelog

- 2026-10-22: по отдельному согласованию [установлен и проверен собственный контур телеметрии](test/telemetry-stand-20261022.md): закреплённый sender 1.0.7/SQLite 3.53.4, лёгкий heartbeat без загрузки приложения, отдельная mTLS-готовность, минутное завершение Prometheus и автоматическая инициализация только своего тома. Logs/traces/metrics подтверждены в центральных проекциях; остатки gateway/sender — 2/3, бюджет издателя не изменён. Прежние 13 файлов PKI/grants сохранены; центральный приёмник не обновлялся. Зафиксирована операторская ошибка: финальный stdout/stderr удалённого предшественника не архивирован, полную сохранность технического вывода утверждать нельзя. Ruff/Black/Pyright и 99 тестов прошли, две пропущенные Compose-проверки выполнены отдельно на хосте.

- 2026-10-22: по отдельному согласованию добавлен публичный операторский `renewal.py describe`: закрытая читающая проекция действующего клиентского одобрения, identity, SHA-256 CA/scope и путей публичных выходов. Общая существующая блокировка берётся только для чтения и без ожидания; ключи/approval/аудит не выдаются, файлы/права/таймеры не меняются, отзыв и несогласованные данные закрывают результат. Артефакт трёх прежних модулей с описью выпускается отдельно через `Dockerfile.renewal`; runtime Dockerfile и установленный gateway не меняются.

- 2026-10-18: издатель принимает канонический JSON readiness с ограниченным чтением; новая контейнерная проба из закреплённого клиента 1.1.1 проверяет только собственный heartbeat без загрузки gateway и TLS. Права клиентов и журнал публикации не меняются.

- 2026-10-18: по согласованному объёму ADR-0113 добавлены отдельное операторское одобрение автоматического продления локального client/server leaf и неизменного scope grant, общий барьер apply/revoke/renewal, запрет восстановления отзыва и публичная диагностика сроков/последнего сбоя. TLS-контексты обоих входов обновляются без рестарта; инструменты выпуска и CA key не попадают в runtime. Локальный таймер macOS не заменяет production SPIRE или согласованную смену CA.

- 2026-10-15: `/healthz` и `/readyz`, OpenAPI и собственный healthcheck переведены с общего текстового `ok` на единые JSON-ответы ADR-0134 без изменения mTLS/grant-защиты `/v1/fetch`.

- 2026-10-14: apply/revoke разрешений получили отдельный fsync-журнал безопасности с фазами intent/committed, хеш-цепочкой и закрытым отказом до мутации при повреждении цепочки или невозможности сохранить intent. Добавлены OTLP logs/traces, продолжение `traceparent`, production-проверка HTTPS/mTLS и собственный telemetry sender с постоянным журналом, Prometheus и правилами. Изолированная сборка проходит 62 теста, Ruff и строгий Pyright; продукт получил `PRODUCTION_READY`, а подключение канонического audit collector, WAN и SPIRE остаётся допуском площадки.

- 2026-10-14: свежая изолированная сборка прошла 58 тестов, Ruff и строгий Pyright. Статус остаётся `IN_PROGRESS`, пока операторские изменения не подключены к обязательному защищённому аудиту и поставка не получила собственную устойчивую телеметрию.

- 2026-10-14: README сокращён до назначения, состава и быстрого запуска; руководство дополнено подготовкой провайдера и навигацией Swagger, а карта, спецификация, endpoints и история разделены по назначению. Runtime не изменён.

- 2026-10-13: добавлен `ENDPOINTS.md` с полным описанием Swagger/OpenAPI, read-only documentation listener, mTLS/grant-защищённого fetch, тела запроса, ответных заголовков, ошибок и технических проб.

- 2026-10-12: Swagger/OpenAPI собственного backend, три группы `default`/`gateway`/`metrics`, общие с parser поля/ограничения и закреплённые локальные файлы Swagger UI 5.33.1. Собственный `DOCS_PUBLIC_URL` публикуется как Swagger-ссылка в ревизии 2 группы/gateway; издатель не наследует ссылку. HTTPS-вход только для чтения в том же процессе не запрашивает клиентский ключ, закрыто отклоняет POST с 405 и не проксирует fetch. Защищённый API и mTLS/индивидуальные права сохранены; добавлены регрессии и реальные HTTPS/состояние/браузерные проверки, без новых контейнеров или рабочего каталога потребителей.

- 2026-10-12: [проверка переноса](test/validation-result.md): 42 собственные регрессии и 60 транспортных/конфигурационных проверок потребителей/корня, строгие типы и форматирование. Реальные native/общий lifecycle, оба init IdP/UI, смена состояния и подтверждённая отписка прошли; временные ресурсы очищены, рабочая история не менялась. Диагностика TCP/TLS раннего отказа сохраняет корректное тело без понижения TLS. Географические и production-допуски отделены от локального результата.

- 2026-10-12: ADR-0114: самостоятельный инфраструктурный gateway вместо исходного shared-дерева и клиентских контейнеров. Собственные Compose/env/TLS, разрешения на exact SPIFFE URI, отдельные квоты и scopes, hot revoke/expiry, операторская подготовка и статус. Fetch-форма и универсальные DNS/IP/TLS запреты сохраняются; неаутентифицированный local-вызов больше не поддерживается. Python 3.13.7/Bookworm сохранены. История прежней поставки — в Git и `shared/obsolete/public-egress-gateway`.
