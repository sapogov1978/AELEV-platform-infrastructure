# Проверка переноса Public Egress Gateway

Дата: 2026-10-12. Python runtime: 3.13.7, Debian Bookworm; версии ОС и Python не изменены.

Этот отчёт фиксирует перенос до доработки Swagger; её отдельный повторный прогон и 58 текущих собственных проверок описаны в [отчёте Swagger](swagger-result.md). Ссылки ниже на lifecycle/состояние содержат последние реальные прогоны, не отменяют хронологию исходного переноса.

Результат локальной реализации: PASS. Это не допуск целевой production-платформы.

| Проверка | Результат |
|---|---|
| Прежние проверки сетевой политики до изменения | 18 пройдены на прежнем коде и закреплённом Python |
| Текущая политика, индивидуальные права/квоты, expiry/revoke, отсутствие fallback настроек | 42 пройдены в финальном собственном checks-образе |
| Black, Ruff, строгий Pyright шлюза | Без ошибок |
| Согласованность Poetry metadata/lock и собственного UI wheel | Подтверждена, без изменения runtime-зависимостей клиентов |
| Zone Ingestion: обязательный mTLS, CZDS, Range/resume и сохранение байтов | 11 пройдены; Ruff/Pyright без ошибок |
| Base Screening: обязательный mTLS и сохранение identity в сетевом driver | 9 пройдены; Ruff/Pyright без ошибок |
| Compose потребителей: локальная сеть, собственный удалённый маршрут, отсутствие контейнера провайдера | 3 Zone Ingestion + 3 Base Screening + 4 Source Research пройдены |
| Регрессии верхнеуровневой оркестрации | 30 пройдены |
| Реальные собственный/общий запуск, HTTPS/mTLS, запреты, квоты, отзыв, перезапуски и очистка | [PASS жизненного цикла](lifecycle-result.md) |
| Настоящие Keycloak/PostgreSQL/UI, повторный provisioning, OIDC/PKCE, публикации, отказ/восстановление и отписка | [PASS профиля состояния](status-result.md) |
| Kubernetes-рецепты потребителей | YAML, обязательные env, projected grants, встроенный Python и shell-синтаксис проверены; кластер не запускался |

Всего 102 текущие модульные/конфигурационные проверки, без пропущенных проверок в этих наборах. Сетевой lifecycle и профиль состояния выполнены отдельно; unit-результат не подменяет контейнерные сценарии. Проверены ссылки, Markdown-якоря, закрытие блоков, заголовки Mermaid и отсутствие действующих сборочных путей в `shared/public-egress-gateway`. Старый runtime-каталог удалён; исторические документы сохранены вне инфраструктуры.

Все временные проекты и записи удалены, существующие ресурсы и состояния контейнеров сохранены. Рабочие архивы не получали диагностических метрик. Рабочие потребители не переключены, общий комплекс полностью не перезапускался. `.env`, TLS, разрешения и приватные ключи остаются вне Git.

Не выполнялись: реальный Kind/CNI-сценарий (на машине отсутствует `kind`), WAN/географическое и нагрузочное испытание, автоматическая SPIRE-ротация, защищённый подписанный аудит, рабочий rollout/rollback потребителей. Эти допуски остаются в [TASKS](../TASKS.md), а не получают PASS из локальных тестов. Подготовленный локальный gateway env и серверная PKI не являются production identity; издатель для рабочего UI отдельно подготавливается по README. Коммит и пуш в этой задаче не выполнялись.
