# Public Egress Gateway — профиль состояния

UTC: 2026-10-12T11:16:54.895171+00:00

Результат: PASS

- Реальные канонические Keycloak/PostgreSQL/UI/API в отдельном проекте и томах; рабочая инфраструктура не используется для тестовых записей.
- Настоящая собственная одноразовая подготовка identity: два exit 0, идемпотентный secret, без административных файлов в издателе.
- mTLS/JWT-публикация принята реальной оболочкой; две составные строки ONLINE, без функционального раздела.
- Реальный UI принял Swagger-ссылку владельца и gateway-компонента; адрес задан для браузера, не внутренним Docker DNS.
- Настоящий Chromium отрисовал Swagger: default → gateway → metrics и /v1/fetch; без клиентского сертификата и CDN. Временный профиль доверял только ключу тестового сервера, системное доверие не изменялось.
- При остановке gateway его компонент перестаёт быть ONLINE, издатель остаётся ONLINE; восстановление получает новую подтверждённую последовательность.
- Штатная остановка издателя подтверждает отписку: строка исчезает из динамического списка.
- Тестовые контейнеры, сети, тома, образы, секреты и UI/IdP записи удалены вместе с изолированным стендом; рабочий архив не изменялся.

WAN, SPIRE-ротация, защищённый аудит и аппаратная MFA этим сценарием не проверялись.
