Образ, модульные проверки и реальный fetch используют прежние Python 3.13.7 / Debian Bookworm. Операторские драйверы запускались уже существующим `python3` станции; установка или смена Python/ОС не выполнялись. Swagger UI 5.33.1 — тот же закреплённый выпуск, что у переводчика, с проверкой оригинальных SHA-256 при сборке. Браузер загружает схему и файлы только у самого gateway; внешний CDN/валидатор не используется.

Первоначальный браузерный прогон завершился FAIL: один HTTPS-вход с необязательным mTLS всё равно запрашивал клиентский сертификат до HTTP; сетевой журнал Chrome подтвердил `SSL_CLIENT_AUTH_CERT_NEEDED` (−110). Его значение определено в [официальном исходнике Chromium](https://raw.githubusercontent.com/chromium/chromium/main/net/base/net_error_list.h). Решение — отдельный вход только для чтения в том же процессе/контейнере, не ослабление fetch. Он не запрашивает клиентский ключ, любой POST возвращает 405 даже разрешённому клиенту и не проходит через авторизацию/проксирование. OpenAPI указывает отдельный настоящий mTLS-адрес fetch; в Swagger исполнение разрешено только техническим GET. Повторный полный прогон прошёл. Также устранена потеря отчёта при ошибке проверки очистки; окончательные контейнерные сценарии выполнены последовательно, без замены исходных проверочных образов во время описи.

Временный профиль браузера доверял только ключу своего тестового сервера через явный `--allow-local-certificate`; глобальные настройки, корпоративные политики, Keychain и личный профиль не изменялись, клиентские ключи браузеру не передавались. Это не проверка доверия рабочего корпоративного браузера к production-сертификату: оператор должен доставить доверенную серверную цепочку с правильным SAN и доступным браузеру `DOCS_PUBLIC_URL` по [README](../USER_MANUAL.md#swagger-и-группы-endpoints).

Ссылка подтверждена в настоящем API оболочки, Swagger отрисован настоящим браузером; автоматическое нажатие кнопки в полном UI этим сценарием не выполнялось. Рабочий gateway/его publisher не разворачивались, рабочие потребители не переключались, диагностические метрики в рабочий архив не передавались. WAN/Kubernetes, SPIRE-ротация, защищённый аудит, масштабная нагрузка и аппаратная MFA не проверены. Состав инфраструктуры, доменные контракты и полномочия платформенной оболочки этой доработкой не расширены. Коммит и пуш не выполнялись.
