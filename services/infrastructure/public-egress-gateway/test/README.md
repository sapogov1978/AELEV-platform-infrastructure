# Проверки Public Egress Gateway

Команды сборки и запуска закреплены в [README поставки](../USER_MANUAL.md#6-ошибки-и-наблюдение). `test_gateway.py` проверяет сетевой барьер и точную форму fetch; `test_authorization.py` — индивидуальные права, доверие, лимиты, горячий отзыв и закрытый отказ конфигурации. Оба запускаются штатным pytest на Python 3.13.7. `test` исключён из обычного Docker-контекста и передаётся явно только checks-target.

`test_documentation.py` проверяет три группы OpenAPI, совпадение со строгим parser, pinned Swagger-файлы, собственный публичный origin и публикацию ссылки без наследования издателем. Native lifecycle проверяет настоящие HTTPS-документацию/схему/файлы и прежний отказ fetch без mTLS. Status lifecycle проверяет ссылку в реальном API UI; с явными `--chromium` и `--allow-local-certificate` дополнительно проверяет DOM настоящего Swagger и сохраняет снимок. Это не автоматическое нажатие кнопки всей оболочки: её действующее представление не меняется, публикация подтверждается реальным контрактом. Рабочее системное доверие не изменяется.

`lifecycle.py` собирает скопированную самостоятельную поставку, создаёт временную PKI, использует реальные публичные HTTPS-байты и проверяет собственный/общий Compose. `status_lifecycle.py` проверяет настоящий IdP/UI и обе одноразовые подготовки в отдельном стенде; ни один init не исключается ради успешного результата. Сценарии учитывают исходные контейнеры, сети, тома, образы и состояния; очищают только доказанно созданные ими ресурсы. Запускайте их последовательно, без одновременной внешней очистки исходных ресурсов.

Читаемые результаты: [актуальная проверка готовности](production-readiness-result.md), [сводная проверка переноса](validation-result.md), [доработка Swagger](swagger-result.md), [жизненный цикл](lifecycle-result.md), [состояние](status-result.md). Каждый отчёт отделяет выполненные этапы от внешних допусков; старый полный lifecycle инфраструктуры не выдаётся за повторённый этим переносом. Новые диагностические ряды в рабочий архив не отправляются.
