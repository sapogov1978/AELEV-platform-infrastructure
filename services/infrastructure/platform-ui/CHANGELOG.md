# Changelog

- 2026-10-29: оболочка больше не подключает в свой DOM владельческий `/presentation/v6.css` с глобальными правилами компоновки; её левая навигация, страница состояний и iframe восстановлены возвратом к неизменяемому shell presentation v5. Владельческий v6 по-прежнему передаётся в изолированные iframe; оба опубликованных артефакта сохранили байты и SHA-256.

- 2026-10-29: SDK Platform UI 0.1.4 экспортирует канонические путь и SHA-256 неизменяемого `/presentation/v6.css`; приложения больше не дублируют digest, а проверка сопоставляет метаданные SDK с фактическими байтами. Порядок каскада восстановлен без изменения опубликованного CSS.

- 2026-10-29: выпущены неизменяемый `/presentation/v6.css` и `@aelev/operator-ui-kit` 0.1.3 с единым `PlatformPage`. Исходник SDK перенесён в поставку Platform UI, автономный `presentation.css` побайтно совпадает с публичным артефактом, а прежние `v1`–`v5` не изменены.

- 2026-10-28: потеря status publisher больше не подменяет последнее владельческое наблюдение полным отказом сервиса. API добавочно возвращает `reported_state`, а оболочка показывает обычный цвет последнего состояния и отдельное красное «Нет связи с издателем» с прежним временем; эффективное устаревшее `state` остаётся `UNKNOWN`.

- 2026-10-28: оболочка сохраняет независимый `/healthz` nginx, но `/readyz` теперь требует готового `platform-ui-api`, поэтому статическая страница не выдаётся за готовую панель состояний при мёртвом приёмнике. Три постоянные роли получили явный допуск к точной регистрации в единственном recovery-контроллере с native `restart=no` и обязательной передачей истории при замене.

- 2026-10-28: свежий владельческий `OFFLINE` теперь отображается оранжевым «Недоступен», поскольку живой сервис может быть ограниченно функционален из-за одного компонента. Красный цвет и надпись «Нет связи» оставлены только для `connection=LOST`; контракт состояний и байты прежних presentation CSS не менялись.

- 2026-10-27: локальный publisher CA получил отдельный owner-оператор подготовки и перекрывающей доставки нового 365-дневного корня без автоматического удаления прежнего. Удостоверение SPIRE status publisher обновляется отдельной 90-дневной задачей Telemetry Delivery; CA-ключ не передаётся издателю или runtime, а production-команды закрыто требуют внешний PKI/KMS/HSM/Vault.

- 2026-10-27: по ADR-0161 добавлен необязательный owner-controlled `navigation_order`: левое меню сортирует функциональные модули по возрастанию без каталога продуктов и случайного порядка UUID. Отсутствие и `null` сохраняют прежние канонические байты и значение `0`; равенство стабилизируется по `module_id`.

- 2026-10-23: собственный издатель использует SQLite 3.53.4 при прежних Python/ОС/SDK и явную конечную restart-политику. Полный журнал проверяется до замены; UUID, последовательность и прежний бюджет сохраняются. Проверка сборки не подменяет фактическую установку.

- 2026-10-18: технический клиент 1.1.1 получил автономную локальную heartbeat-пробу для `python -S`, без загрузки приложения, TLS или сетевых соединений. Прежние сообщения, журнал и байты выпуска 1.1.0 сохранены; добавлены отказные проверки и совместимость транспорта.

- 2026-10-15: Выпущен неизменяемый `/presentation/v5.css` с визуальными примитивами Policy Management для opt-in-контейнера `.aelev-owner-ui`: общий фон, типографика, заголовки, панели, карточки, поля, обычные кнопки, сообщения и диалоги больше не задаются каждым iframe отдельно. Навигация, предметные сетки, метрики, технические и опасные действия остаются у владельцев; `v1`–`v4` сохранены побайтно и доступны с CORS/SRI.

- 2026-10-15: Shell и API реализуют единые JSON-пробы ADR-0134: `/healthz` возвращает `{"status":"ok"}`, `/readyz` — `{"status":"ready"}`; API разделил `/api/healthz` и `/api/readyz`, а собственные container healthcheck и status publisher используют readiness endpoint и проверяют каноническое тело.

- 2026-10-14: nginx начинает отдавать текущий `/presentation/v3.css` с тем же CORS-заголовком, что неизменяемые `v1` и `v2`; SRI-загрузка общего оформления во внешнем owner iframe больше не отклоняется браузером.

- 2026-10-14: общая палитра обычных и вторичных кнопок опубликована новым неизменяемым `/presentation/v3.css` и применяется как оболочкой, так и принявшими закреплённый SHA-256/SRI внедрёнными UI. Семантические навигационные, метрические, технические и опасные действия не превращаются в основные кнопки; `v1` и `v2` сохранены побайтно.

- 2026-10-14: тёмные кнопки и кнопочные ссылки оболочки получили более светлую контрастную палитру Policy Management (`#20523e`, при наведении `#2b684f`) с согласованными рамкой, тенью и состояниями фокуса/отключения. Кнопки логотипа и раскрытия строк сохраняют прозрачное навигационное оформление; публичный `/presentation/v2.css` и оформление внедрённых сервисов не менялись.

Свежая изолированная проверка: 207 тестов прошли. После сверки OIDC, публикации/отзыва, восстановления и UI-жизненного цикла продукт отмечен `PRODUCTION_READY`.
