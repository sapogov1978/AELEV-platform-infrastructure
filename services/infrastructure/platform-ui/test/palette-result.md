# Platform UI — восстановление палитры

Дата: 2026-10-09. Итог: PASS.

Возвращены прежние тёмно-зелёные фоны и мятные акценты. Новая компоновка, авторизация и инъекция страниц не изменены. [Снимок работающего интерфейса](palette-preview.png).

- [Проверки поставки](checks-result.md): 29 Python-тестов, 8 проверок frontend, Black, Ruff, строгий Mypy, TypeScript/Vite и собственный Compose пройдены. Две регрессии проверяют неизменность опубликованного CSS и прежнюю палитру при новой компоновке.
- Собственный контейнер интерфейса пересобран и обновлён; nginx и API здоровы. API, IdP и чужие контейнеры не перезапускались.
- Обе версии CSS получены по HTTPS с проверкой CA: байты совпали с собственными файлами, заголовки CORS и неизменяемого кеша сохранены. SHA-256 публичной конфигурации совпал с текущим `v2.css`; прежний `v1.css` не изменён.
- Настоящий вход через Keycloak, переключение языка и выход проверены Chromium. Ошибок JavaScript нет. Фон — `rgb(7, 16, 14)`, акцент — `#48d4a4`, шапка — `rgb(10, 20, 18)`, боковая панель — `rgb(9, 21, 18)`. При окне 1440×1000 высота шапки осталась 88 px, ширина боковой панели — 240 px.
- Проверены восемь Markdown-файлов и 101 локальная ссылка, парность ограждений кода, отсутствие маркеров конфликтов и `git diff --check`. Временное браузерное окружение удалено; снимок и отчёты сохранены в собственном `test`.

Полный жизненный цикл на этом цветовом изменении не повторялся: его [предыдущий результат](lifecycle-result.md) относится к прежнему прогону. Рабочая поставка оставлена для ручной проверки; браузерный сеанс завершён. Игнорирование недоверенного локального сертификата применялось только в изолированном браузерном контексте, доверие системы и проверки TLS приложения не менялись.
