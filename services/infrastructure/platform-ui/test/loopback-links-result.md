# Platform UI — внешние локальные HTTP-ссылки

Дата: 2026-10-11. Ограниченное исключение по ADR-0108 применяется только к внешним `ui_url`/`swagger_url`, не к iframe, входу, публикации метаданных или удалённому HTTPS. Универсальная оболочка не содержит адреса/идентификатора переводчика или другого конкретного потребителя.

| Проверка | Результат |
|---|---|
| `pytest -q` в штатном Python 3.13 образе с актуальными API/тестами | 198 passed |
| `npm test` в штатном закреплённом Node-образе с актуальными исходниками/тестами | 97 passed, 4 файла |
| Собственная Compose-сборка API/оболочки | PASS; TypeScript/Vite production build |
| `ruff check api.py test` | PASS |
| `black --check api.py test/test_api.py` | PASS |
| `mypy api.py` | PASS |

Проверены точные `localhost`, `127.0.0.1`, `::1`, запрет удалённых, сокращённых/целочисленных адресов, credentials, неоднозначного IPv6, нулевого порта, фрагментов, обратной косой черты и управляющих символов. HTTPS-ссылки и прежние канонические байты сохранённых описаний совместимы; HTTPS iframe не расширен. Ссылка открывается отдельно с `noopener noreferrer`, без токена оболочки и Referer. Настоящий вход в интерфейс проверяет его владелец в собственном `test`, без фиктивных публикаций оболочке.

Полный `black --check api.py test` обнаруживает прежнее замечание в неизменённом `test/status_publication.py`; исправление этого файла не входит в изменение ссылок. Python-тесты сообщают два прежних предупреждения Starlette об устаревшем тестовом интерфейсе. SQL, WAN, production PKI и полный остановочный цикл поставки здесь не проверялись. Обновлены только два собственных рабочих контейнера без удаления метаданных, идентификаторов и последовательностей.
