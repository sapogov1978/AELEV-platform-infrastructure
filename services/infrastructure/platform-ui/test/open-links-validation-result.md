| Оболочка, навигация, индикатор, ссылки и браузерные примеры | 85 Vitest-тестов, PASS |
| Keycloak: собственный издатель и конфигурация | 36 Python-тестов, PASS |
| Grafana: собственный издатель и конфигурация | 16 Python-тестов, PASS |

| Корневая конфигурационная граница и безопасность тестовых инструментов | 33 Python-теста, PASS |

Black, Ruff и строгий MyPy изменённых Python-файлов прошли; отдельно проверены типы read-only браузерного теста. TypeScript и production-сборка Vite прошли. Проверки сервисов выполнялись на закреплённом Python 3.13.7, frontend — на закреплённом Node 22.18.0. ОС, рабочие версии продуктов, Python и публичный клиент 1.1.0 не заменялись. Операторский браузерный прогон использовал уже установленный Chromium, Playwright 1.56.0 и существующий host Python 3.14.8 в отдельном временном окружении, не в рабочем сервисе.

Регрессии проверяют прежние канонические байты при отсутствии/null новых полей, устойчивость ссылок после перезапуска API, владение, ревизии, приоритет UI/Swagger, отсутствие наследования ссылки родителя, запрет UI-ссылки у функционального модуля с внедрёнными разделами и его компонентов. Отклоняются plaintext, относительные/неоднозначные адреса, credentials, фрагменты, управляющие символы, неверный порт/тип и origin оболочки; frontend дополнительно проверяет адрес до отрисовки. Публичный клиент передаёт прежний формат точных байтов; нового артефакта или общего образа нет.

Настоящий браузер после OIDC-входа сверил все группы и компоненты с API без подмены ответов, открыл Grafana, Prometheus, Blackbox Exporter и административную консоль Keycloak. Проверены отдельные вкладки, отсутствие opener и Referer, реальное содержимое страниц; без собственной ссылки кнопки нет. Prometheus и Blackbox Exporter использовали явно предоставленный операторский сертификат: mTLS не отключался, удостоверение издателя не передавалось браузеру. Локальная тестовая PKI допускает только явное исключение доверия браузера на loopback; рабочие TLS-проверки сохранены. [Подробный браузерный результат](open-links-live-result.md), [снимок](open-links.png), [тест](open_links.py).

Первый frontend-запуск не получил необходимый существующим тестам USER_MANUAL.md в контейнере проверок; после добавления read-only mount полный прогон прошёл. Первый браузерный прогон обнаружил пустое тело самостоятельного приложения сразу после DOMContentLoaded; тест теперь ждёт непустое реально отрисованное содержимое с ограничением 15 секунд и повторно прошёл на окончательных образах. Сетевые ответы и состояния не подменялись, шаги не исключались.

Обновлены только nginx/API оболочки и четыре собственных издателя. Идентификаторы 63 остальных Compose-контейнеров сохранены; нативные процессы, тома, identities и секреты не удалялись. Браузер закрыт, временных контейнеров проверок нет. Рабочие сервисы оставлены запущенными. Общий Compose с профилем ui разрешается без ошибки; этот прогон не является повторным полным остановочным жизненным циклом инфраструктуры.

У переводчика Swagger сейчас отключён, консоль MinIO выключена; Kafka, Loki, Tempo и транспортные роли не получают выдуманных ссылок. Реального функционального издателя со Swagger в этой установке нет: соответствующее правило проверено контрактными и frontend-тестами, не фиктивной публикацией. WAN, внешняя PKI, резервное восстановление, нагрузка и административные действия в целевых приложениях не проверялись. Два предупреждения устаревших API в существующем TestClient не являются отказом; зависимости не менялись ради их устранения.
