Python: `docker run --rm -v /var/run/docker.sock:/var/run/docker.sock aelev/platform-ui:checks pytest -q test`. Socket доступен только временной операторской проверке Compose; постоянным nginx/API/издателю он не выдаётся. UI: `docker run --rm --network none -v <own-test-directory>:/work/test:ro -v <own-manual>:/work/USER_MANUAL.md:ro aelev/platform-ui:frontend-checks npm test`. Образы checks/frontend-checks собираются из закреплённых аргументов собственного env и сервисных тестов по README. Браузерные аргументы — в [README](../PROVIDER_OPERATIONS.md#собственное-состояние-в-platform-ui).

Полный браузерный отчёт: [status-publication-result.md](status-publication-result.md), [снимок](status-publication.png). Потеря собственного приёмника проверяется как `UNKNOWN` в уже открытом интерфейсе: отключённый API не способен принять и показать свежий отчёт о своём отказе. После восстановления проверен свежий `ONLINE`; срок состояния остановленного издателя истёк по реальному серверному времени.

Временные проверочные контейнеры удалены через `--rm`; браузерный тест не создаёт identities, контейнеры, сети или тома. Рабочие nginx/API и собственный издатель оставлены для ручной проверки, данные и журналы сохранены. Локальный PASS не доказывает WAN, продукционную PKI/SVID или аппаратное ограждение PostgreSQL. Корневая оркестрация целиком не запущена из-за отсутствующих прежних прикладных параметров.
