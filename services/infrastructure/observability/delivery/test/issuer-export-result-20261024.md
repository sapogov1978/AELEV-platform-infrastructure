# Читающий экспорт публичных issuer — 24 октября 2026

Владелец отдельно согласовал `export-issuers` и подключение его к установщику Advance. Объём не включает выдачу, смену CA/ключей, новые таймеры или обновление sender/приёмника. [Нормативный контракт](../SPEC.md#читающий-экспорт-публичных-issuer) принадлежит прежнему оператору; потребитель не читает его `state.json`/`approval.json`.

Добавлены проверка точного владельца/неизменности одобрения, отказ по отзыву, неподтверждённой ротации и изменённому CA/leaf. Публичный сертификат сверяется с закреплённым хешем, цепочка и срок проверяются прежним OpenSSL. Приватные ключи не читаются, выпуск и запись состояния не вызываются. Повтор возвращает те же публичные байты. Тест с запретом чтения обоих private key и полной сверкой прежних файлов прошёл; отрицательные случаи не исправляют регистрацию.

Первый узкий набор — **12 passed**, строгий MyPy изменённого оператора, Ruff и Black чистые. С HTTP/TLS-регрессиями — **40 passed**, весь собственный набор — **118 passed**, 42,35 с. Первый расширенный запуск по ошибке использовал системный LibreSSL: фикстуры не получили AKI, современный строгий Python TLS их отверг. Повтор с документированным OpenSSL 3 прошёл без изменения проверки TLS или продукта. Общая инфраструктурная venv также не содержала SDK издателя; полный набор прошёл с собственными закреплёнными wheel через `PYTHONPATH`, без новых зависимостей или чужих исходников.

Использован прежний закреплённый Python 3.13.7/Alpine 3.22, без новых зависимостей. Это локальный ARM64-образ, не подписанная многоархитектурная публикация. Capability `io.aelev.telemetry.issuer-export=1` разрешает только получение публичного интерфейса установщиком; рабочая служба не создаётся.
