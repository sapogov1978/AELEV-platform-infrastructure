# Observability: спецификация слоя оркестрации

Нормативные источники: [ADR-0107](../../../docs/adr/20261011-0107-independent-observability-products.md), [ADR-0082](../../../docs/adr/20261007-0082-self-contained-service-delivery.md), [ADR-0100](../../../docs/adr/20261009-0100-durable-owner-telemetry-delivery.md), [контракт телеметрии](../../../docs/api/telemetry.md). Команды — в [README](README.md).

Слой — композиция семи самостоятельных технических продуктов, не общий runtime. Процессы, env, шаблоны, секреты, тома, миграции/инициализация, Poetry lock, метрики, панели и тесты принадлежат продуктам. Агрегатор содержит только include канонических Compose, имя группы, имя включаемого env и последовательный вызов команд подготовки. Функциональные потребители неизвестны инфраструктуре.

Полные разрешённые модели самостоятельного, общего observability и корневого инфраструктурного запуска совпадают. Каждый продукт создаёт только свою сеть между нативным процессом и издателем; его технические зависимости задаются защищёнными маршрутизируемыми endpoints. Docker bridge не пересекает hosts. Нативный процесс не ожидает UI/IdP; потеря зависимости честно отражается readiness, архив delivery сохраняет задолженность.

Шесть постоянных томов и семь журналов издателей сохраняются при stop/down без --volumes. Маркер DATA_OWNER независим от Compose project; его точное прежнее значение сохраняется при миграции. Непустые немаркированные/чужие данные не усыновляются. Инициализатор каждого владельца без сети/секретов получает только его том. Одновременные писатели самостоятельной и общей группы запрещены.

UI-контракт, identities, UUID, ревизии и последовательности, TLS/mTLS, сроки технических проекций, бессрочный архив и SMTP с STARTTLS сохраняются. Публичная библиотека подготовки поставляется внутри владельца как версионированный wheel с SHA-256; общего рабочего образа, imports соседних исходников или файлового доступа к чужому серверу нет. Общий слой не хранит панели продуктов и не заменяет собственный Prometheus отправителя.

Проверки слоя сравнивают полные разрешённые модели и исключают общий runtime/env и внешние mounts. Нативные процессы, доставка и UI проверяются владельцами на настоящих компонентах с сохранением существующих данных и прочих проектов. Исторические отчёты не считаются результатом нового запуска. Локальная готовность не доказывает WAN/PKI, резервное восстановление, нагрузку или высокую доступность.
