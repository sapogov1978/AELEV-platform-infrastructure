Команды из корня репозитория:

```sh
docker build --target checks --build-context tests=services/infrastructure/observability/test -t aelev/observability-checks:local services/infrastructure/observability
docker run --rm --network none aelev/observability-checks:local ruff check prepare.py initialize.py test
docker run --rm --network none aelev/observability-checks:local black --check prepare.py initialize.py test
docker run --rm --network none aelev/observability-checks:local mypy prepare.py initialize.py test
docker run --rm --network none aelev/observability-checks:local pytest -p no:cacheprovider -q test/test_configuration.py test/test_prepare.py
```

Первая дополнительная попытка сборки с `--network none` не прошла: смена режима сети не использовала прежний кэш установки Poetry, а загрузка пакета была запрещена. После этого штатная документированная сборка прошла из кэша; сами проверки исполнялись без сети.

Это ограниченная регрессия конфигурации, не повторный полный жизненный цикл Grafana, не испытание подключения панелей реальных потребителей и не подтверждение доставки телеметрии через Kafka. Предыдущая проверка реальных продуктов сохранена [отдельно](lifecycle-result.md). Рабочие env, секреты и данные не менялись; образ проверок сохранён для повторного запуска.
