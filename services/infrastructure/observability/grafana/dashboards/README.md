# Панели Grafana

Этот каталог принадлежит Grafana. `infrastructure.json` показывает готовность технических ролей наблюдения, доступность собственных источников метрик, задолженность/ошибки доставки и заполнение исходного журнала. Запросы ограничены собственными техническими заданиями Prometheus и не выбирают ряды потребителей.

Каждый наблюдаемый сервис сам определяет состав, смысл, единицы измерения и метки своих метрик, запросы, оформление панелей и предметные правила уведомлений. Их исходники и тесты хранятся внутри поставки сервиса-владельца, не здесь и не в корневой оркестрации. Observability не создаёт панель сервиса по факту получения его метрик.

При развёртывании владелец явно подключает свою версионируемую панель к Grafana по HTTPS API; файловая доставка оператором также допустима. Пошаговые действия, отдельная учётная запись с правом Edit своей папки, проверяемый JSON, команды публикации и запрос данных приведены в [USER_MANUAL](../USER_MANUAL.md); рабочая копия не становится вторым редактируемым источником. Владелец использует отдельный `uid`, не `aelev-infrastructure`; при файловой доставке не занимает `infrastructure.json`. Подключение — административная операция развёртывания, не доступ приложения к удалённой общей файловой системе. Учебный пример не добавлен в runtime или каталог потребителей Grafana.
