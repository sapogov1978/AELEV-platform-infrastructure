# Проверки самостоятельной поставки prometheus

Дата: 2026-10-11. Итог локальных проверок: PASS.

- Собственный образ собран только из каталога владельца; Python 3.13.7 и закреплённые нативные версии сохранены.
- 16 модульных и конфигурационных проверок — PASS: канонический Compose, отсутствие запасных env, собственные mounts/сеть, точный digest публичного артефакта и прежние проверки издателя.
- Black 26.3.1, Ruff 0.13.2 и строгий MyPy 1.18.2 изменённого кода и новых проверок — PASS.
- Настоящая собственная prometheus-configuration-init — exit 0; прежний маркер/том принят без смены владельца, одноразовый контейнер удалён через run --rm.
- Реальные контейнеры запускаются из собственного Compose; HTTPS/mTLS readiness и свежая подтверждённая ONLINE-публикация — [отчёт запуска](startup-result.md).

Рабочие данные, UUID, identities и журналы сохранены. Контейнеры оставлены работающими для проверки оператором. Изменения границ зафиксированы ADR-0107; корневая композиция включает эту модель без поправок.

Полный новый stop/start всех компонентов и браузерный цикл не повторялись. WAN, production PKI/ротация, нагрузка, независимое резервное восстановление и внешняя отправка почты не проверялись. Старые отчёты не подменяют этот результат.
