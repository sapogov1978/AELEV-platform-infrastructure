# История инфраструктурной оркестрации

- 2026-10-29: ограниченный хостовый recovery-оператор получил точные действия `relocate` и `release-relocation` для согласованного переноса цели между Compose project/service/name. Новый контейнер обязан быть healthy, прежний Docker ID — отсутствовать; история, guard, автоматический режим и накопленные попытки сохраняются без reset или нового бюджета. Намерение переживает потерянный ответ, частично завершённый пакет целей идемпотентно продолжается, а защитная блокировка переносится с `restart=no` и снимается только отдельным доказательством точной новой инкарнации. Для доказанного pre-write отказа прежнего helper с `RELOCATION_UNCONFIRMED` добавлено fail-closed продолжение того же запроса с digest состояния до/после и восстановлением неизменного таймера; остальные ошибки не ремонтируются автоматически.

- 2026-10-28: по ADR-0171 recovery различает длительную паузу хоста и рабочий отказ, ждёт owner-declared Compose dependencies без расхода attempts и автоматически передаёт историю устойчивой здоровой замене того же точного Compose scope. Ручной suspend, guard, неопределённое воздействие и работающий предшественник остаются закрытыми. Изменяющая операторская команда до 120 секунд ждёт окончания активного прохода вместо требования вручную останавливать таймер.

- 2026-10-28: хостовое recovery-окно больше не требует вечного существования завершённого одноразового macOS-helper: после устойчивого `COMPLETE` его отсутствие допускается только по сохранённой квитанции точной схемы и того же daemon. Незавершённые, повреждённые, чужие и работающие операторы по-прежнему закрыто блокируют нового writer; журнал, attempts и таймер не очищаются.

- 2026-10-27: ADR-0166 распространил обязательный owner-declared lifecycle на все активные локальные leaf. `certificate_lifecycle.py` обнаруживает распределённые approvals без центрального каталога, требует ровно один загруженный таймер, свежую квитанцию, точный хеш и безопасный запас leaf/CA; 7-дневный Egress использует собственный трёхдневный порог без продления grant. Keycloak, MinIO и UI Policy Management переведены с отдельных file mounts на каталоги, совместимые с атомарной заменой inode.

- 2026-10-27: по ADR-0165 общий локальный оператор продления получил проверяемую схему установки owner-scoped volumes и fail-closed deployment gate. Восемь сертификатов наблюдения SPIRE обслуживаются тремя раздельными задачами с 90-дневным leaf, 30-дневным окном, минутным циклом, свежими квитанциями и сохранением истории без передачи CA-ключей runtime.

- 2026-10-27: согласование ранее отправленного автоматического восстановления больше не расходует единственный Docker action прохода и не удерживает готовое восстановление других точных целей. Регрессия воспроизводит незавершённый `DISPATCH_INTENT` с `AUTOMATIC_RESULT_UNCONFIRMED`; повтор команды по-прежнему запрещён.
