## Реализационные ограничения

Keycloak пока передаёт ADMIN_PASSWORD/DATABASE_PASSWORD через постоянные env, не через файловую доставку в память/tmpfs. Ограничение прямо описано в README и добавлено в TASKS относительно ADR-0017; chmod 600 .env не объявляется достаточной production-защитой.

Переводчик монтирует весь SECRET_ROOT. Вложенный UI_ADMIN_ROOT шаблона доступен рабочим ролям через этот bind; новая инструкция предлагает runtime/status-admin вне SECRET_ROOT. Раздельная файловая изоляция runtime/deployment Kafka identity ещё требует исправления mounts. README/TASKS отмечают ограничения; существующие env и файлы этой документационной правкой не перемещены.

Проверки не подтверждают внешнее хранилище секретов, production SVID/автоматическую ротацию, настоящий отзыв CA, смену действующих SQL/OIDC/SMTP-паролей, корпоративное доверие браузера, WAN, Kubernetes/watchdog, резервное восстановление данных или SMTP. Прежние отчёты не переписывались; runtime-поведение, версии, реальные секреты и контейнеры не менялись.
