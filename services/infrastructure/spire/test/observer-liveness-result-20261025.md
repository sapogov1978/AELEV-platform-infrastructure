# Проверка живости observer и восстановление sender — 25 октября 2026

По отдельному согласованию исправлен только observer; затем операторски запущен прежний sender без замены SDK. SPIRE Server, status-publisher, центральный приёмник, identities и очереди не переключались. Нормативное поведение принадлежит [SPEC](../SPEC.md#собственное-наблюдение).

## Подтверждённая причина

Прежний observer считал возраст всего цикла вместо возраста последнего завершённого ограниченного подшага. В сохранённой диагностике полный цикл имел возраст 15,330 с, но текущая фаза `HTTP_REPLY` — только 0,195 с: поток продолжал работу. Проверка после записи диагностики могла использовать уже устаревшее наблюдение.

Теперь прогресс обновляется после фактически завершённых ограниченных операций, включая устойчивую запись, сетевой ответ и подтверждение журнала. Простая смена диагностической фазы не продлевает живость. После диагностики повторяется проверка: восстановившийся поток не завершается, настоящее зависание или смерть потока сохраняют отказ. Пределы 15/2 с, таймауты HTTP и правила подтверждения пакетов не повышались.
