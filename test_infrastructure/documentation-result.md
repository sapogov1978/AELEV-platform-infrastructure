# Аудит документации инфраструктуры

Дата: 2026-10-11. Проверена документация действующей рабочей копии main; ранее начатые изменения сохранены. Это аудит документации и читающая проверка конфигурации, не новый полный жизненный цикл или production-допуск. Образы, версии, контракты, env, удостоверения, данные и рабочие контейнеры этим аудитом не менялись.

## Выявленные реализационные ограничения

Текущий translator-service не обеспечивает мигратору/worker выход к удалённой PostgreSQL: обе роли подключены только к translator-data с internal: true. README и руководство больше не называют одно изменение DATABASE_HOST готовым распределённым запуском; задача отмечена [у владельца](../translator-service/TASKS.md). Kafka имеет только PLAINTEXT listener: клиентское SSL не заменяет защищённый broker; соответствующий [допуск](../kafka/TASKS.md) остаётся открытым.

Локальный генератор удостоверений MinIO содержит устаревший потребительский SAN. Это отмечено в [TASKS MinIO](../minio/TASKS.md); генератор, уже выданные удостоверения и рабочие контейнеры не менялись. Исправление этих реализационных ограничений не выдаётся за выполненную документационную работу.
