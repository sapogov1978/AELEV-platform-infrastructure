# Проверка безопасности операторских инструментов

Дата: 2026-10-10. Итог: PASS. Python 3.13.7 и Poetry 2.2.1 не менялись; проверка выполнена в изолированном окружении на macOS. Рабочая инфраструктура не перезапускалась.

| Проверка | До обновления | После обновления |
| --- | --- | --- |
| Версия Black | 25.9.0 | 26.3.1 |
| Версия pytest | 8.4.2 | 9.0.3 |
| 30 существующих проверок оркестрации | PASS | PASS |
| Путь к кэшу Black с опасным `python_cell_magics` | Выходит за каталог кэша: дефект воспроизведён | Остаётся внутри каталога: PASS |
| Подмена временного каталога pytest собственной символической ссылкой | Ссылка принята: дефект воспроизведён | `OSError`, каталог назначения не изменён: PASS |
| Форматирование обычного Python-кода и сохранение AST | PASS | PASS |
| Все существующие и новые тесты | Новые защиты дают 2 ожидаемых FAIL, обычное форматирование — PASS | 33 PASS |
| Black, Ruff и строгий Mypy | Исторический результат сохранён отдельно | PASS, четыре Python-файла |

Два защитных теста сначала запущены против уязвимых версий в изолированном контейнере Python 3.13.7: получены 2 FAIL и 1 PASS. После обновления те же три проверки проходят и в контейнере, и в собственном операторском окружении. Тест Black только вычисляет путь, не пишет за пределами кэша; символическая ссылка pytest ведёт исключительно в собственный временный каталог теста. Никаких чужих файлов или общих каталогов не подменяли.

В этом Poetry lock изменились только записи Black/pytest и контрольный хеш манифеста. Остальные версии, зависимости, артефакты и Playwright 1.56.0 сохранены. `poetry check --lock` проходит; предупреждения Poetry об устаревшей форме метаданных не маскируются и не требуют смены схемы проекта для устранения этих уязвимостей.

Исправления производителей: [Black, CVE-2026-32274](https://github.com/psf/black/security/advisories/GHSA-3936-cmfr-pm3m), [pytest 9.0.3, CVE-2025-71176](https://github.com/pytest-dev/pytest/releases/tag/9.0.3). Это безопасность операторских инструментов, не новый транспорт, административная роль или изменение оркестрации.

Команды повторения приведены в [README](README.md). Данный прогон не запускает `lifecycle.py` и не заменяет [реальное испытание жизненного цикла](lifecycle-result.md).
