# Platform UI — итог проверки

Дата: 2026-10-10. Итог самостоятельной поставки: PASS.

- [Проверки поставки](checks-result.md): 41 Python-тест моделей/API/владения/JWT/конфигурации/оформления, 42 проверки frontend, Black, Ruff, строгий Mypy, TypeScript/Vite и собственный Compose. Runtime и Python-тесты используют закреплённый Python 3.13; версии техстека не подменялись. Два предупреждения Starlette/httpx/anyio сохранены, не объявлены исправленными.
- [Жизненный цикл](lifecycle-result.md): 27 успешных этапов с настоящими nginx, API и инфраструктурным Keycloak, включая обе одноразовые настройки, вход/выход, JWT/mTLS, инъекцию, изоляцию, проверенное оформление, перезапуск, `UNKNOWN` и очистку с совпадением исходной описи Docker.
- После очистки выполнен отдельный обычный запуск. nginx/API и Keycloak/его PostgreSQL здоровы; вход первого оператора, отсутствие тестовых модулей и выход проверены браузером. [Снимок рабочей оболочки](manual-preview.png). Эти четыре рабочих контейнера намеренно оставлены для ручной проверки; чужие контейнеры не изменялись.
- Проверены 24 затронутых Markdown-файла, 417 локальных ссылок, парность ограждений кода, маркеры конфликтов и `git diff --check`. Старые инструкции сохранены в `obsolete`, ссылки на историческую проверку proxy обновлены.
- Отдельно проверено разрешение относительных контекстов/секретов трёх расширений оболочки из уровня инфраструктуры; соседние исходники не требуются. Полный корневой Compose не запускался: его проверка остановилась на незаполненном прежнем `AELEV_INFRASTRUCTURE_ZONE_BUCKET_ACCESS_KEY`, не относящемся к оболочке. Значение не выдумывалось, чужие настройки не менялись.

Границы: локальная PKI не заменяет доверенные production-сертификаты, длительную проверку WAN, ротацию, резервное восстановление и допуск цепочки поставки. Подключение реальных страниц выполняет каждый владелец по техническому контракту; готовность оболочки не объявляет эти подключения выполненными. Секреты и живой env не коммитятся; коммит и push на этом этапе не выполнялись.

После восстановления прежней палитры выполнены повторные проверки поставки и отдельная [проверка оформления](palette-result.md). Текущий [снимок интерфейса](palette-preview.png) отражает зелёную палитру; снимки выше и отчёт полного жизненного цикла сохраняют результаты предыдущего прогона.

После уточнения названия выполнены девять frontend-тестов (включая шапку и HTML title), TypeScript/Vite и сборка собственного контейнера. Работающий nginx обновлён без перезапуска API/IdP; по HTTPS с проверкой CA подтверждены `Discovery Research Platform` во вкладке и новая подпись в загружаемом JavaScript. Палитра, размеры и контракты не менялись; Python-проверки и полный жизненный цикл для этой текстовой правки не повторялись.

После добавления одного общего индикатора по ADR-0102 выполнены повторные проверки поставки и 22 успешных этапа [браузерной проверки](refresh-result.md): положение слева от кнопки состояния, управление из произвольного HTTPS UI, ошибка/восстановление, защита источника, сохранение времени, сброс при смене или перезагрузке iframe и минутный последовательный опрос оболочки. Неверное техническое ожидание через `wait_for_function` заменено совместимым со строгой CSP чтением DOM; CSP не ослаблялась. SQLite не получила тестовых модулей, identities не создавались; iframe и ответ с его описанием существовали только в проверочном браузерном контексте. Полный жизненный цикл повторно не запускался, реальные владельцы должны отдельно внедрить сообщения в своих UI.

Финально проверены 15 Markdown-файлов, 259 локальных ссылок, ограждения кода, отсутствие маркеров конфликтов, заголовок Mermaid и `git diff --check`. nginx/API здоровы, число активных модулей в настоящей SQLite осталось равным нулю. Временное браузерное окружение удалено; тест, отчёт и снимок сохранены в `test`, рабочие контейнеры оставлены для ручной проверки.

## Функциональное меню — 2026-10-10

После подтверждения расширения контракта добавлен необязательный `service_kind` от владельца. Меню «Подключенные сервисы» показывает только `FUNCTIONAL`; `INFRASTRUCTURE`, отсутствие поля и `null` сохраняются в состоянии. Регрессии проверяют прежние канонические байты и идемпотентность, допустимые/недопустимые значения, устойчивое хранение типа, владельца и новую ревизию. 41 Python-тест, 42 проверки frontend, форматирование, анализ, строгие типы, конфигурация и сборки прошли по [отчёту](checks-result.md).

В [браузере](refresh-result.md) пройдено 29 этапов: смешанные типы, русский/английский заголовок, исключение только из меню, закрытие iframe при смене типа и отсутствие автоматического повторного открытия, прежние индикатор/минутный опрос/источник, узкий экран и настоящий вход/выход через Keycloak. [Снимок меню](service-navigation-preview.png) содержит только произвольные фикстуры браузера, не подключённые реальные сервисы. Первое ожидание завершилось `TimeoutError`; отдельный обычный вход не выявил ошибки JavaScript, два последующих полных браузерных прогона успешны, один из них — документированной командой без диагностической трассировки. Причина первоначального таймаута не подтверждена.

Образы API/nginx обновлены, оба контейнера здоровы. Хеш всех записей метаданных и аудита до и после совпал; активных модулей по-прежнему 0. Временные браузер и HTTPS-сервер закрыты, временный venv удалён; рабочие контейнеры и постоянный том намеренно сохранены для ручной проверки. Проверены 11 Markdown-файлов, 150 локальных ссылок, ограждения, пробелы, маркеры конфликтов, заголовок Mermaid и `git diff --check`. Полный жизненный цикл, общий Compose и миграция реальных издателей повторно не выполнялись: владельцы добавляют тип новой ревизией по [контракту](../../docs/api/platform-ui-injection.md#инъекция), а прежние описания без типа остаются только в состоянии.
