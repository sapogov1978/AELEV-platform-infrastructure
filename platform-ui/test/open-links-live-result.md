Проверка только читает настоящие публикации и открывает их страницы. Каталога продуктов, фиктивных модулей, identities, контейнеров, сетей и томов нет; браузер закрыт. Клиентские удостоверения предоставлены оператором явно, токен оболочки целевым страницам не передаётся. Исключение доверия локальной PKI допустимо только с явным флагом и только для loopback; рабочие проверки TLS/mTLS не меняются. Swagger функционального UI проверяется отдельными контрактными/модульными регрессиями: отсутствие такого живого издателя не подменяется фиктивной публикацией. WAN, внешний CA и целевые административные действия этим тестом не проверяются.
