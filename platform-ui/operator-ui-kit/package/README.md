# Platform UI SDK

Версионированный SDK Platform UI для самостоятельных и внедряемых операторских React-приложений. Канонические классы и оформление принадлежат Platform UI; приложения-владельцы добавляют только предметную разметку, состояния и локальные специализации.

## Основные возможности

- Панели очередей и процессов.
- Единый `PlatformPage` с платформенными корнем, заголовком, рабочей областью и нейтральными слотами.
- Точный автономный снимок текущего `/presentation/v6.css`; это производная поставки Platform UI, а не второй редактируемый источник.
- OIDC/PKCE и самостоятельное либо встроенное окно.
- Общий опрос и защита несохранённых форм.

## Запуск и проверки

Это библиотека, не отдельное приложение. Публичные экспорты перечислены в [package.json](package.json); проверки выполняются приложением-потребителем по его руководству.
