# Клиент Platform UI

Самостоятельная Python-библиотека публикации технического описания и состояния владельца в Platform UI.

## Основные возможности

- HTTPS/JWT/mTLS.
- Устойчивая последовательность и точные повторы.
- Присутствие, штатная отписка и локальная проба.

## Запуск и проверки

Из этого каталога: `poetry build --format wheel`. Владелец включает закреплённый wheel в свою поставку; подключение описано в [руководстве](USER_MANUAL.md).
