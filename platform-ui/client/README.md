# Клиент Platform UI

Самостоятельная Python-библиотека публикации технического описания и состояния владельца в Platform UI.

Версия 1.1.2 явно задаёт SKI/AKI при первоначальной операторской выдаче client certificate, одинаково для OpenSSL и системного LibreSSL. Runtime-протокол, schema, права, health и состояние издателя не изменены; существующие удостоверения не перевыпускаются автоматически.

Закреплённый [wheel 1.1.2](../public/presentation/client/1.1.2/aelev_platform_ui_client-1.1.2-py3-none-any.whl): SHA-256 `d7fc03eee7df98d906a5390505a15e67c008fbeccd856f73ac0d5c67f62efb86`. [Отчёт проверки](VERIFICATION-1.1.2.json) отделяет проверку компонента от обновления потребителей и допуска полной инфраструктуры.

## Основные возможности

- HTTPS/JWT/mTLS.
- Устойчивая последовательность и точные повторы.
- Присутствие, штатная отписка и локальная проба.

## Запуск и проверки

Из этого каталога: `poetry build --format wheel`. Владелец включает закреплённый wheel в свою поставку; подключение описано в [руководстве](USER_MANUAL.md).
