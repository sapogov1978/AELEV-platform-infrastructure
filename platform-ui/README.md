# Platform UI

Операторская оболочка для разделов и технических состояний, опубликованных владельцами сервисов.

## Основные возможности

- Общий вход и навигация.
- Декларативный порядок функциональных разделов, задаваемый их владельцами.
- Изолированное встраивание самостоятельных UI.
- Единый версионированный `PlatformPage` и presentation CSS для самостоятельных и внедряемых UI; приложения добавляют только предметные блоки и локальные специализации.
- Раздельное отображение последнего владельческого состояния и свежести связи с его издателем.
- Отдельное локальное полномочие publisher CA с явной перекрывающей ротацией по ADR-0166; в production используется внешний issuer.

## Запуск

После подготовки по [руководству](PROVIDER_OPERATIONS.md), из этого каталога:

```sh
docker compose config --quiet
docker compose up -d --no-build --pull never
```

Первоначальная сборка, обновление и восстановление описаны в руководстве. При работе через общую инфраструктурную композицию не запускайте отдельный проект поверх тех же данных.

UI-сборка устанавливает security patches в принятой Alpine 3.22 и работает под UID 101. CI сохраняет scan/SBOM фактического image ID по [общему правилу проверки образов](https://github.com/sapogov1978/discovery-research-platform/blob/8d1a663319ac15d8729cf1422858f37d57096c75/docs/security/supply-chain.md).
