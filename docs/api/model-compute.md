# Непрозрачная граница исполнения перевода

Platform Infrastructure не определяет общий API модели, её версии, обучения, размещения или допуска. Унаследованное имя этого документа сохраняет путь ссылки; прежняя модельная спецификация потребителя находится только в [аудиторском архиве](../audit/pre-1.0-api-documents.tar.gz) с [описью](../audit/pre-1.0-api-documents.json).

Инфраструктурный Translator принимает технический запрос текста и языков по [Kafka-контракту](translation.md), сохраняет его и пользуется непрозрачным портом исполнения по [00-INFRA-20261106-0012-translator-technical-capability](../adr/00-INFRA-20261106-0012-translator-technical-capability.md). Он получает текст результата либо ограниченную техническую ошибку. Порт не сообщает переводчику модель, её версию, внутренний cache, checkpoints или способ перевода.

Провайдер самостоятельно владеет своей реализацией и её жизненным циклом. Выбор локального процесса, отдельного образа, внешнего API или иной реализации не принят этим документом. Нельзя выводить из старого standalone-рецепта обязательную compute-ячейку, дополнительную инфраструктурную capability или provider-specific поля публичного запроса.

Без выбранного/доступного провайдера Translator сохраняет принятую работу, dedup и историю. [Полная локальная приёмка](../operations/clean-room-reproduction.md) проверяет именно эту гарантию и Kafka outage/restart; она не заявляет качество или выполнение перевода невыбранным провайдером. Его последующее подключение требует отдельной проверки совместимости, полномочий, capacity и отказов по [руководству владельца](../../translator-service/USER_MANUAL.md).
