# INFRA-ADR-0002: Имя и корень инфраструктурного репозитория

- **Статус:** Принят по явному требованию владельца от 2026-11-06
- **Дата:** 2026-11-06
- **Основание:** INFRA-ADR-0001, ADR-0082, ADR-0103, ADR-0104
- **Частично заменяет (Supersedes):** INFRA-ADR-0001, ADR-0103 и ADR-0104 только в части имени GitHub-репозитория и расположения исходного дерева; владение, стек, Kafka-контракты и жизненный цикл сохраняются

## Решение

Канонический репозиторий получает имя `sapogov1978/AELEV-platform-infrastructure`. Самостоятельные владельцы находятся прямо в корне: `kafka`, `postgresql`, `minio`, `keycloak`, `spire`, `public-egress-gateway`, `platform-ui`, `translator-service`, `observability`; вложенные владельцы наблюдаемости сохраняют своё размещение внутри `observability`. Корневые Compose, установщик и метаданные выпуска также находятся в корне. Повторяющий назначение репозитория уровень `services/infrastructure` удаляется из активных исходников.

Пакет формата 2 сохраняет пути относительно этого корня. Он включает полную нужную документацию и инструменты, исключая только `graphify-out` и `.codex`. Опись, исходный commit, SHA-256 и правила безопасной материализации остаются обязательными; потребитель поддерживает формат 1 для исторических выпусков и формат 2 для новых. CLI `./infrastructure` и предметные интерфейсы не меняются.

Физический путь установленного экземпляра не зависит от структуры Git. Существующая установка DRP сохраняет `services/infrastructure` как локальный каталог зависимости: её secrets/env/runtime, Compose labels, mounts и volumes не переносятся. Это не каталог исходников в Git DRP. Смена закреплённого выпуска выполняется отдельно с проверкой прежних байтов; автоматического пересоздания данных или возобновления очередей нет.

Прежние README и CHANGELOG общей композиции сохраняются в `docs/obsolete/services/infrastructure`; актуальная точка входа — корневой README и CHANGELOG. Ссылки, CI inventory, security baselines, схемы поставки и диаграммы переносятся вместе с кодом. Зарегистрированный RMS key `PlatformInfrastructure` и локальный путь checkout сохраняются, поскольку переименовывается GitHub-репозиторий, а не внешний vault.

## Проверка и откат

Проверяются отсутствие активного уровня `services/infrastructure` в Git, все 19 Python-проектов и UI в CI, прежние 15 диаграмм владельцев и композиции, сборка и чистый `init`, полный SHA-256 нового архива и совместимость Windows transport. Старые tags и выпуски остаются доступны под новым именем репозитория; откат выбирает прежний совместимый выпуск, не удаляя данные и историю.
