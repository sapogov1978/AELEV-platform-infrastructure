# ADR-0071: Постепенное применение локализации предметной политики

> **Происхождение standalone-редакции.** Источник: `docs/adr/obsolete/20261003-0071-progressive-policy-localization.md`; SHA-256: `0191bf258f6d43ca9372fe43edd94b3e19680e892c4f575e2ae49db2ce64072b`; основание включения: цепочка замены. Сохранены номер, статус, история замены и применимые решения; упоминания исключённых bounded contexts нейтрализованы без переноса их контрактов.

- **Статус:** Заменён ADR-0129
- **Дата:** 2026-10-03
- **Основание:** A5, A10, A12, ADR-0057, ADR-0069, ADR-0070
- **Заменяет (Supersedes):** требование ADR-0057 использовать буквальные локализованные сигналы только после завершения всего профиля и предварительную полную локализацию в ADR-0070 только для описанного ниже раннего положительного маршрута; остальные решения сохраняются

## Контекст

Перевод всего словаря до первой проверки задерживает обработку языка на десятки минут. Оператор явно потребовал переводить выражения по одному, сохранять накопленный результат и запускать независимые задания языков. Неполный словарь не позволяет доказать отсутствие положительных признаков или наличие всех исключений.

## Критерии выбора

- один переводный запрос содержит одно исходное выражение одного языка;
- готовая единица сохраняется до следующего запроса и переживает перезапуск;
- раннее применение не превращает неполный профиль в допущенный полный профиль;
- независимые задания не требуют копирования тяжёлых весов и не смешивают происхождение ответов.

## Рассмотренные альтернативы

1. Ожидать перевода всех выражений. Отклонено: сохраняет обнаруженную задержку первого полезного результата.
2. Использовать отсутствие совпадений в неполном словаре как отказ. Отклонено: теряет релевантные документы и ещё не переведённые исключения.
3. Сохранять единицы по очереди и разрешать раннюю проверку полного исходного профиля только при положительном сигнале. Принято.

## Решение

Каждое выражение переводится отдельным ограниченным запросом и сохраняется с точными исходными байтами, языками, выпуском переводчика, запросом и ответом. Одна точная пара policy/base-language имеет одно исключительное задание и отдельного работника на время исполнения. Ограниченный пул таких работников обслуживает разные языки независимо; общий закреплённый вычислитель переводчика выдаётся между отдельными запросами по FIFO без смешивания языковых контекстов и без обязательного копирования тяжёлых весов.

Сохранённые проверенные единицы могут давать производное `partial_profile`, но не получают `READY` или право на буквальное отрицательное решение. После перевода предметной области и хотя бы одного положительного выражения найденный сигнал разрешает раннюю контекстную проверку исходного полного профиля. Отсутствие сигнала, неполный список исключений, техническая ошибка и неподтверждённое измерение сохраняют ожидание. Ранний автоматический маршрут разрешён только проверенному categorical-ответу полного исходного профиля по прежнему точному admission либо действующему временному разрешению ADR-0070. Это не допуск частичного переводного профиля и не изменение области модели. Отказ точной страницы не закрывает другие ожидающие разделы домена.

Прогресс одного языка не используется другим и не сбрасывается повторным наблюдением языка. Готовая локализация используется без нового перевода. При изменении положительных переведённых сигналов ожидающие ещё не решённые оператором цели могут пройти triage заново; история человека никогда не заменяется машиной. Полный профиль получает `READY` только после прежней проверки состава и языка.

## Последствия

Первое полезное совпадение может участвовать в обработке до окончания всего языка. Готовые выражения и готовые локализации не переводятся повторно. Ошибка одного языкового задания не меняет прогресс другого. Общий вычислитель по-прежнему ограничивает суммарную пропускную способность; отсутствие положительного сигнала до завершения перевода остаётся ожиданием, а не отказом.

## Критерии проверки

Тесты проверяют раннее совпадение, отсутствие ложного буквального отказа по неполному словарю, неизменность полного исходного профиля классификатора, исключительность lease, продолжение после перезапуска и повторное использование готовой локализации. Эксплуатационные измерения отдельно фиксируют время первой единицы и завершения полного языка; увеличение числа работников не является доказательством ускорения общего вычислителя.

## Миграция и откат

Обновление не меняет межсервисных контрактов или формат готовой локализации: `partial_profile` — восстанавливаемая проекция прежнего сохранённого прогресса. Приложение, API и UI обновляются согласованно. Откат приложения отключает ранние сигналы, но не удаляет контрольные точки, готовые переводы или историю решений.
