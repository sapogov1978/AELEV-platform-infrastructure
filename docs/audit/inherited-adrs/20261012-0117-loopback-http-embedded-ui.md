# ADR-0117: Loopback HTTP для внедряемых локальных UI

> **Происхождение standalone-редакции.** Источник: `docs/adr/20261012-0117-loopback-http-embedded-ui.md`; SHA-256: `0f1412a8351ed47bab1def53d2be5e6a214168a04f8987747b59e3e727df53db`; основание включения: прямая ссылка из поставки. Сохранены номер, статус, история замены и применимые решения; упоминания исключённых bounded contexts нейтрализованы без переноса их контрактов.

- **Статус:** Принят по явному архитектурному требованию пользователя
- **Дата:** 2026-10-12
- **Основание:** A10, A12, ADR-0017, ADR-0082, ADR-0101, ADR-0108
- **Частично заменяет (Supersedes):** ADR-0101 и ADR-0108 только в обязательности HTTPS для `sections[].url` на точном loopback; изоляция iframe, самостоятельная авторизация, HTTPS удалённых адресов и защита публикации сохраняются

## Контекст

Самостоятельный UI владельца обязан тем же артефактом подключаться к Platform UI. В локальной установке браузер не должен требовать добавления частного CA в системное доверие macOS только ради внедряемой страницы. Проброс TLS-listener владельца на loopback без доверенной браузером цепочки делает формально опубликованный раздел неработоспособным и нарушает цель инъекции.

## Решение

`sections[].url`, `ui_url` и `swagger_url` могут использовать HTTP только с точным hostname `localhost`, `127.0.0.1` или `::1`. Порт должен находиться в диапазоне `1..65535`; учётные данные, фрагменты, сокращённые или целочисленные IP, поддомены `localhost`, обратная косая черта и неоднозначные URL запрещены. Владелец локальной поставки публикует порт только на loopback. Любой не-loopback адрес остаётся HTTPS.

Оболочка разрешает эти точные источники в `frame-src`, сохраняет sandbox и проверяет точные `origin` и `source` сообщений. Она не передаёт iframe свои токены, не проксирует API и не ослабляет авторизацию владельца. Loopback обозначает компьютер браузера, а не контейнер или удалённый сервер. Production-профиль владельца публикует отдельный HTTPS origin с доверенной цепочкой.

HTTP loopback считается браузером потенциально доверенным адресом, но это ограниченное локальное исключение, а не транспорт между сервисами. Издатель по-прежнему обращается к Platform UI по HTTPS с JWT/mTLS; OIDC остаётся HTTPS.

## Последствия

Один UI-артефакт работает самостоятельно и внутри Platform UI без установки локального CA в системное доверие. Локальный трафик UI не шифруется, поэтому публикация на `0.0.0.0`, LAN-адрес или имя хоста запрещена. Удалённая и production-установка не получает HTTP-исключения.

## Критерии проверки

- API принимает точные loopback HTTP URL раздела и отклоняет remote/неоднозначные HTTP URL.
- CSP оболочки допускает точный локальный HTTP frame, а протокол представления проверяет его HTTP origin.
- UI владельца доступен по опубликованному loopback HTTP адресу самостоятельно и из iframe без добавления CA в хранилище ОС.
- HTTPS публикации, OIDC, sandbox и production-профиль не ослабляются.

## Миграция и откат

Сначала обновляются API и CSP оболочки, затем владелец публикует loopback HTTP URL с большей ревизией и пересоздаёт только свой UI/API/издатель. Для отката владелец сначала публикует HTTPS URL в ещё большей ревизии, после чего можно вернуть прежнюю оболочку. UUID, sequence, тома и доменные данные не сбрасываются.
