# ADR-0057: Только локально исполняемые и дообучаемые модели crawler

> **Происхождение standalone-редакции.** Источник: `docs/adr/20260921-0057-local-only-crawler-model-eligibility.md`; SHA-256: `83e7c24bbb2cfac892319eec09c7f56348a4ab0c42697476c13cf44913529d8d`; основание включения: прямая ссылка из поставки. Сохранены номер, статус, история замены и применимые решения; упоминания исключённых bounded contexts нейтрализованы без переноса их контрактов.

- **Статус:** Частично заменён ADR-0129: модели и перевод исключены из `base-screening`; ограничения локального исполнения сохраняются для последующих модельных стадий; прежняя общая терминология частично заменена [ADR-0152](20261019-0152-retire-discovery-registry-umbrella.md), остальные действующие решения сохраняются
- **Дата:** 2026-09-21
- **Основание:** A5, A10, A12, ADR-0031, ADR-0049
- **Заменяет:** ADR-0055 и ADR-0056

## Контекст

ADR-0055 обязал production-классификатор исполняться и дообучаться локально, но оставил удалённые модели в составе экспериментов crawler. ADR-0056 закрепил правильный локализованный каскад, однако также разрешил удалённый API как исследовательский ориентир. Это создало код, тесты, образы, секреты и документацию для кандидатов, которые заведомо не могут быть выбраны рабочей моделью, и расходовало время на несопоставимые испытания.

Crawler является переносимым самостоятельным продуктом. Проверяемый кандидат должен быть доступен не только для разового сравнения, но и для воспроизводимого локального исполнения, предметного дообучения по операторским решениям, независимой проверки и эксплуатации без обязательного внешнего поставщика модели.

## Критерии выбора

- полный inference запускается в принадлежащей развёртыванию инфраструктуре без обращения к внешнему модельному API;
- лицензия разрешает локальное использование и требуемое предметное дообучение;
- веса, токенизатор, конфигурация и runtime закрепляются по версии и хешу;
- новый выпуск воспроизводимо обучается, калибруется и проверяется на разделённых `TRAIN`, `VALIDATION` и `HOLDOUT`;
- кандидат может пройти одинаковый закрытый контракт и измерение ресурсов на реальных сохранённых документах crawler.

## Рассмотренные альтернативы

1. Сохранять удалённые модели как ориентир качества. Отклонено: результат нельзя продвинуть в продукт, а обёртка, сетевой доступ и секреты образуют отдельный неиспользуемый контур.
2. Разрешить локальный inference без возможности дообучения. Отклонено: такой кандидат не может адаптироваться по операторским решениям и не удовлетворяет назначению crawler.
3. Испытывать только локально исполняемые и законно дообучаемые модели. Принято.

## Решение

Все рабочие и экспериментальные модели `web-discovery-crawler`, включая переводчик, embedding-модели и контекстный классификатор, должны полностью исполняться локально и поддерживать законное локальное дообучение для требуемого сценария. Модель, доступная только через внешний API, а также модель без доступных весов или без права на требуемое дообучение, не входит в код, тестовую матрицу, образы, конфигурацию или список кандидатов crawler.

Межмодельное сравнение сохраняет независимую обёртку каждого кандидата, общий закрытый контракт результата, одну неизменяемую матрицу реальных документов и единый агрегатор. Каждая обёртка работает без внешней сети после предварительного получения и проверки закреплённых артефактов. Измеряются ошибки по языкам и классам, калибровка, задержка, пропускная способность, память, CPU/GPU и размер образа; рекламные измерения поставщика не считаются результатом crawler.

Локализованный каскад ADR-0056 сохраняется: профиль переводится один раз для точной пары policy/language, буквальные однозначные исходы завершаются до модели, а контекстный классификатор получает только неоднозначный фрагмент конкретной страницы или повторяемого раздела. Операторские метки и жизненный цикл обучения ADR-0055 также сохраняются: рабочие веса не меняются онлайн, новый выпуск создаётся отдельно и не продвигается без независимой проверки и возможности отката.

## Последствия

Положительные:

- каждый испытанный кандидат в принципе может стать рабочим выпуском;
- crawler не содержит неиспользуемых клиентов внешних моделей, секретов и сетевых разрешений;
- результаты воспроизводятся на принадлежащей развёртыванию инфраструктуре;
- операторские решения могут улучшать выбранную модель через проверяемый выпуск.

Отрицательные:

- недоступные локально модели нельзя использовать даже как внешний ориентир;
- получение и хранение весов требует диска, памяти и контроля лицензий;
- для крупных кандидатов нужны отдельные локальные CPU/GPU испытания.

## Критерии проверки

- в исходном коде, тестах, образах и конфигурации crawler нет клиента удалённого модельного API;
- тестовая матрица перечисляет только кандидаты с доступными локальными весами и допустимым дообучением;
- модельный runtime завершает полный тест при запрещённом исходящем сетевом доступе;
- точный model lock проверяет версии и хеши всех исполняемых артефактов;
- новый выпуск нельзя продвинуть без воспроизводимого локального обучения, калибровки и независимого holdout.

## Миграция и откат

Удалённые экспериментальные обёртки, их тесты, образы и инструкции удаляются. Исторические записи changelog сохраняются как история ранее выполненной работы, но больше не описывают действующий состав crawler. Откат этого ограничения требует нового ADR; возвращать удалённую модель только тестовым файлом или экспериментальным образом запрещено.
