# Обзор Platform Infrastructure

Продукт объединяет самостоятельные поставки Kafka, PostgreSQL, MinIO, Keycloak, SPIRE, Platform UI, наблюдаемости, Public Egress Gateway и Translator. Общая композиция остаётся точкой совместного технического запуска, а не общим владельцем прикладных данных.

Локальный установочный интерфейс выбирает возможности, готовит только собственные ресурсы инфраструктурных владельцев и запускает их канонические Compose-рецепты. Конкретные ресурсы потребителей создают их владельческие административные задачи. Прикладные сервисы работают через опубликованные технические интерфейсы и публичные Kafka-контракты.

Состав показан в [композиционной диаграмме](../services/infrastructure/infrastructure.mmd), границы выпуска — в [диаграмме репозиториев](architecture/repositories.mmd). Нормативный [интерфейс установки](api/installation.md) отделён от рабочего межсервисного обмена.
