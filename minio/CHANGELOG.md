# История minio

- 2026-11-14: собственная зависимость Platform UI client обновлена до immutable SDK 1.1.2 (SHA-256 d7fc03eee7df98d906a5390505a15e67c008fbeccd856f73ac0d5c67f62efb86): operator prepare явно задаёт SKI/AKI. Runtime/protocol Python-модули побайтно совместимы с 1.1.1; существующие credentials, UUID/sequence, журналы и восстановительные бюджеты этим handoff не меняются.

- 2026-10-27: TLS обоих MinIO sites переведён на правильные `CA:FALSE` leaf и owner-scoped автоматическое продление. Каждый узел монтирует целиком свой `site-a`/`site-b` TLS-каталог вместе с `CAs/aelev-minio-sites.crt`, поэтому атомарная ротация больше не остаётся на старом file-mount inode; восемь узлов проверены rolling recreate без замены data volumes.

- 2026-10-23: собственный издатель использует SQLite 3.53.4 при прежних Python/ОС/SDK и явную конечную restart-политику. Полный журнал проверяется до замены; UUID, последовательность и прежний бюджет сохраняются. Проверка сборки не подменяет фактическую установку.

- 2026-10-19: подключена автономная read-only проба heartbeat из клиента Platform UI 1.1.1 без импорта издателя и сетевых подключений. Сохранены собственные UUID, журнал, пороги и интервалы; нативный провайдер и его готовность не меняются.

- 2026-10-14: локальный генератор сертификатов очищен от потребительского SAN `zone-minio`, добавлена запрещающая возврат регрессия, а документационная проверка env направлена в `USER_MANUAL.md`. Семь конфигурационных тестов проходят; самостоятельный продукт отмечен `PRODUCTION_READY`.

- 2026-10-14: прежний эксплуатационный README перенесён в `USER_MANUAL.md`, а новый README оставлен краткой витриной и быстрым запуском; runtime не изменён.

- 2026-10-11: Добавлены дерево файлов и каталогов, происхождение и подготовка секретов, разграничение локальной и рабочей PKI, права хранения и порядок ротации. Реальные env/удостоверения и рабочие контейнеры не изменяются.

- 2026-10-11: Команды приведены к собственному каталогу. Уточнены подготовка, сборка, site replication, единственный источник PARITY, обслуживание и границы проверок. Устаревший потребительский SAN генератора отмечен как отдельная реализационная задача, без изменения удостоверений.

- 2026-10-10: верхняя строка собственного состояния переименована в «Хранилище артефактов» (`Artifact storage`), ревизия описания 2. Продукты видны внутри прежнего состава; UUID, identity, журнал и последовательность не меняются. Таблица переименований в оболочке не создаётся.

- 2026-10-10: добавлена собственная UI-роль со своими сборкой, identity, journal и env; показания частей публикуются по HTTPS/JWT/mTLS без знания потребителей. Добавлены модульные пробы и Python-проверка реальной страницы при stop/start; native конфигурация не изменена.
