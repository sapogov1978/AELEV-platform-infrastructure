# История minio

- 2026-11-21: R3 M10 выявил пропуск всех четырёх `PROVISION_*` полей в private input pack; base Compose уже передавал их скрипту. Source forwarding не откатывается. Добавлен opt-in bucket-only профиль файловых credentials для owner-prepare: два private grants, stdin root/user passwords, fail-closed FILE pair без fallback и без игнорирования user-add error; legacy inline-ветка сохранена побайтно. Printable ASCII и пределы 4095/4096 проверяются до первого `mc`; raw diagnostics остаётся в private tmpfs. 10 новых shell/config методов и 7 прежних configuration tests PASS, scoped strict types/style и shell syntax PASS; omission model побайтно прежний, selected model меняет только два FILE env paths и два RO mounts bucket-задачи. [История, общий scope, официальные основания и прогноз 45–70 минут](SPEC.md#файловые-credentials-одноразовой-bucket-задачи) записаны до реализации. Новые private harness/preflight/inputs, source seal и native допуск проверяются отдельно.

- 2026-11-21: actual native bootstrap выявил несовместимые per-node `MINIO_ADDRESS`, пропущенные прежними 31 host tests. После history/pinned-source/conflict review routed profile задаёт прежние native ports через штатный `server --address :PORT`; четыре ordered peer URLs и проверяемый `MINIO_*` environment внутри площадки сохраняются. Новая регрессия сначала воспроизвела отказ старого профиля, затем actual Compose проверки сверяют независимые peer environments, CLI/published/target/health alignment и отсутствие иных model deltas. Основания — закреплённый MinIO bootstrap/address algorithm в SPEC; прогноз 35–50 минут до host green и отдельная native квалификация. Base Compose, image-only overlay, runtime image/stack, сети, тома, TLS и write-quorum health не изменены; bypass/RESUME отсутствуют.

- 2026-11-20: после history/source/conflict review добавлен opt-in routed profile для отдельных инкарнаций: native/published ports согласованы, собственный FQDN остаётся локальным, peer DNS направляется на реальные node addresses. Публичный validator закрыто проверяет полный набор восьми узлов, env/resource bindings и optional pinned CA/SAN refs. Health использует прежний установленный `mc ready`, write quorum, CA и timeouts с публичным env alias без credentials. Base Compose, Dockerfile, image-only overlay, старый helper, native image, данные и ключи сохранены побайтно. Host checks и нормализация Compose не объявляют native readiness; прогноз реализации 2–3 часа и отдельной квалификации 45–90 минут, стабильные site endpoints и полный runtime остаются обязательными gates.

- 2026-11-20: точное исключение `!.env.routed.example` включает только новый пустой public template в обычную поставку; реальные `.env*` и secret paths остаются ignored. До изменения проверена существующая owner ignore rule; основание — [Git negated patterns](https://git-scm.com/docs/gitignore#_pattern_format), прогноз — 1 минута. Новые проверки дали 31 PASS, strict mypy/Ruff и Python 3.13 compile; отдельная проверка восьми свежих public leaf/CA refs подтвердила DNS/IP/server-purpose при неизменённых private keys. Это host evidence, native routing/quorum/DAC и stable site endpoints остаются открыты.

- 2026-11-20: полный model audit обнаружил literal server tag, несовместимый с immutable owner-build handoff. Явный `compose.owner-image.yml` меняет только image восьми servers и двух admin tasks; default recipe/tag, stack, mounts, TLS и IDs сохранены. До правки объявлены 25–35 минут на совместную проверку моделей; официальные/internal основания в SPEC. Startup и admission этим не заявлены.

- 2026-11-17: native lifecycle воспроизвёл переназначение общего server tag с новыми Compose project/service labels при одинаковых rootfs layers. Test override теперь использует отдельный `aelev/minio-lifecycle:<run_id>` для всех восьми узлов, provisioners и client, отклоняет занятое имя до effects и удаляет только свой build. История обеих веток и прежнего полного AELEV не содержала такого исправления. Runtime recipe, версии, TLS, erasure topology и 2-ГиБ испытание сохранены. До правки объявлены 25–35 минут на код/проверки; официальный Compose build и границы квалификации приведены в USER_MANUAL.

- 2026-11-15: сборка закрепляет canonical pseudo-versions прежних MinIO/mc commits, официальный Go proxy и checksum database. Полный commit сверяется до сборки, поэтому label не может указывать другую ревизию. Устранён путь динамического hash lookup к отсутствующему Git в builder; Go/OS/runtime, версии, исходники и лицензии сохраняются. Proxy metadata обоих canonical pins проверены; native cold build проверяется отдельным gate.

- 2026-11-14: собственная зависимость Platform UI client обновлена до immutable SDK 1.1.2 (SHA-256 d7fc03eee7df98d906a5390505a15e67c008fbeccd856f73ac0d5c67f62efb86): operator prepare явно задаёт SKI/AKI. Runtime/protocol Python-модули побайтно совместимы с 1.1.1; существующие credentials, UUID/sequence, журналы и восстановительные бюджеты этим handoff не меняются.

- 2026-10-27: TLS обоих MinIO sites переведён на правильные `CA:FALSE` leaf и owner-scoped автоматическое продление. Каждый узел монтирует целиком свой `site-a`/`site-b` TLS-каталог вместе с `CAs/aelev-minio-sites.crt`, поэтому атомарная ротация больше не остаётся на старом file-mount inode; восемь узлов проверены rolling recreate без замены data volumes.

- 2026-10-23: собственный издатель использует SQLite 3.53.4 при прежних Python/ОС/SDK и явную конечную restart-политику. Полный журнал проверяется до замены; UUID, последовательность и прежний бюджет сохраняются. Проверка сборки не подменяет фактическую установку.

- 2026-10-19: подключена автономная read-only проба heartbeat из клиента Platform UI 1.1.1 без импорта издателя и сетевых подключений. Сохранены собственные UUID, журнал, пороги и интервалы; нативный провайдер и его готовность не меняются.

- 2026-10-14: локальный генератор сертификатов очищен от потребительского SAN `zone-minio`, добавлена запрещающая возврат регрессия, а документационная проверка env направлена в `USER_MANUAL.md`. Семь конфигурационных тестов проходят; самостоятельный продукт отмечен `PRODUCTION_READY`.

- 2026-10-14: прежний эксплуатационный README перенесён в `USER_MANUAL.md`, а новый README оставлен краткой витриной и быстрым запуском; runtime не изменён.

- 2026-10-11: Добавлены дерево файлов и каталогов, происхождение и подготовка секретов, разграничение локальной и рабочей PKI, права хранения и порядок ротации. Реальные env/удостоверения и рабочие контейнеры не изменяются.

- 2026-10-11: Команды приведены к собственному каталогу. Уточнены подготовка, сборка, site replication, единственный источник PARITY, обслуживание и границы проверок. Устаревший потребительский SAN генератора отмечен как отдельная реализационная задача, без изменения удостоверений.

- 2026-10-10: верхняя строка собственного состояния переименована в «Хранилище артефактов» (`Artifact storage`), ревизия описания 2. Продукты видны внутри прежнего состава; UUID, identity, журнал и последовательность не меняются. Таблица переименований в оболочке не создаётся.

- 2026-10-10: добавлена собственная UI-роль со своими сборкой, identity, journal и env; показания частей публикуются по HTTPS/JWT/mTLS без знания потребителей. Добавлены модульные пробы и Python-проверка реальной страницы при stop/start; native конфигурация не изменена.
