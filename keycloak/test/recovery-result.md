# Проверка восстановления Keycloak

Дата: 2026-10-14.

Результат: `PASS`.

Полный recovery bundle был создан из отдельной исходной установки и восстановлен в новый Compose-проект с отдельными пустыми PostgreSQL и status-publisher volumes. Проверка manifest подтвердила размеры и SHA-256 всех файлов, восстановленная база прошла проверку realm `aelev`, а согласованная SQLite-копия издателя — проверку UUID, identity и sequence.

После восстановления PostgreSQL и Keycloak перешли в `healthy`. HTTPS OIDC discovery с проверкой восстановленного CA вернул issuer `https://localhost:28444/realms/aelev`.

Для испытания использовался режим `--data-only`: он восстанавливает и проверяет принадлежащие поставке данные без запуска издателя в рабочую Platform UI. Рабочая установка Keycloak, её containers, volumes и сети не останавливались и не изменялись.

Docker исчерпал стандартные автоматически выделяемые IPv4-пулы, поэтому обе тестовые установки временно использовали существующую пустую внешнюю сеть. Это не изменяет результат проверки восстановления; настройка адресных пулов Docker Desktop остаётся отдельной операционной задачей узла.
