# Keycloak

Провайдер человеческих и служебных идентичностей DRP.

## Основные возможности

- OIDC/OAuth 2.0, SSO и восстановление устаревшей формы входа.
- HTTPS с автоматически продлеваемым leaf в едином каталоге владельца и собственная база.
- Подготовка realm и резервное восстановление.

## Запуск

После подготовки по [руководству](USER_MANUAL.md), из этого каталога:

```sh
docker compose config --quiet
docker compose up -d --no-build --pull never
```

Первоначальная сборка, обновление и восстановление описаны в руководстве. При работе через общую инфраструктурную композицию не запускайте отдельный проект поверх тех же данных.

Корневой первичный локальный генератор выпускает цепочку с SKI/AKI для строгой проверки OpenSSL/Python 3.13. Повторная подготовка сохраняет существующие TLS-файлы; смена уже выданного сертификата остаётся владельческой ротацией.

Корневая локальная композиция предоставляет самостоятельным владельцам с `host-gateway` тот же TLS endpoint без общей backend-сети. Bootstrap выбирает private IPv4 gateway Docker bridge на Linux и loopback-публикацию на Docker Desktop. На Linux основной listener остаётся отдельным; CA/SAN обязательны, wildcard `0.0.0.0` и LAN-доступ этим overlay не создаются.
