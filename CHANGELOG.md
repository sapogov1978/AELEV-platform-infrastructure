# Changelog

## 2026-11-05

- Инфраструктура выделена в самостоятельный продукт с исходным кодом всех владельцев, точной историей происхождения применимых ADR, самостоятельной документацией, диаграммами и CI.
- Добавлены публичный локальный установщик выбранных возможностей, проверка владения Compose, исключение модельных/очередных ролей и воспроизводимый пакет исходников с полной описью SHA-256.
- Чистая подготовка проверена без запуска контейнеров; локальные секреты и машинные координаты Graphify явно исключены из Git.
- README и SPEC общей композиции ссылаются на самостоятельный установочный интерфейс и сохраняют ручной владельческий режим эксплуатации.
